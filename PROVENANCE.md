# Materials and dependency notices

The application's license is in LICENSE. Third-party dependencies retain their own licenses and notices and are installed from package-lock.json rather than vendored in this repository. Direct dependency metadata is listed in docs/dependency-licenses.json; consult the installed package's license files for authoritative terms.

The PDFs in fixtures/ are generated from fictional test material by scripts/fixtures.js and scripts/eval-fixtures.js. Screenshots use those fixtures in explicitly labeled mock mode. They contain no user documents and are not evidence of real-model accuracy.

Credentials, runtime data, local logs, personal paths, and build output are excluded from release artifacts. The release manifest lists the intended source snapshot.
